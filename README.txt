PAPERKIT MULTI-PAGE SITE

Files included:
- index.html: homepage linking to the five PDF tools
- merge-pdf.html, split-pdf.html, rotate-pdf.html, images-to-pdf.html, pdf-to-images.html: individual working tool pages
- about.html, contact.html, privacy.html, terms.html: information pages
- styles.css, app.js: shared design and PDF processing logic
- robots.txt, sitemap.xml: basic crawl configuration

HOW TO DEPLOY
1. Download and unzip this package.
2. Open your GitHub repository: https://github.com/officialasad2917-svg/Paper-kit-Pdf-tools-
3. Back up/download the current repository first.
4. Upload/replace the files in the repository root (same folder as the current index.html).
5. Commit changes to the branch used by GitHub Pages.
6. After deployment, test every tool page on desktop and mobile.
7. Check these URLs in a browser:
   /robots.txt
   /sitemap.xml
8. In Google Search Console, submit the sitemap URL:
   https://officialasad2917-svg.github.io/Paper-kit-Pdf-tools-/sitemap.xml

IMPORTANT
- The Contact page contains a reminder to add a real monitored contact method before deployment.
- This is a full-site replacement package. Keep a backup of the current site before replacing files.
- PDF libraries load from public CDNs, so an internet connection is required.
- Test file downloads and all five tools after deployment.
