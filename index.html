How to merge PDF files

  1. Tap Select PDF files and choose at least two PDF documents.
  2. Check the selected files and remove any you don't want included. Files merge in the displayed order.
  3. Tap Merge PDFs & Download. Save the combined PDF to your device.

Frequently asked questions

Is this PDF merger free?

Yes. This demo has no subscription or account requirement. Internet access is needed to load the PDF library the first time.

Are my PDFs uploaded?

The merge code runs in your browser. This page does not send selected PDF files to a server.

Why did a large PDF fail?

Very large files may use too much memory on some phones. Try fewer or smaller files if your browser runs out of memory.

Does it reduce PDF file size?

No. This first version combines PDFs; it does not compress them or perform OCR.
